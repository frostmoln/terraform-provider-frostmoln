# Review guide - terraform-provider-frostmoln

Read by the AI PR reviewer (`AI review` check) alongside `CLAUDE.md`. Keep it short:
what a defect is HERE, and what is not worth a comment.

## A defect here is

- **State dropped, or a Delete reported done, on a 404 that is not a service verdict.** A new
  `resp.State.RemoveResource` or "gone" Delete is gated on `client.IsNotFound`, a predicate that
  also checks `FlatEnvelope` (`vpc_route` `isRouteNotFound`), or a successful read/list showing
  absence (incl. a soft-deleted `status: deleted`) - never a bare `StatusCode == 404` / `Code ==
  "NOT_FOUND"`; a routing 404 stays an error (`client.go` `FlatEnvelope`, `internal/failclosed`,
  `docs/guides/not-found-handling.md`).
- **A schema change that destroys or strands existing state.** Renaming or removing an HCL
  attribute bumps the resource's own schema `Version` with an upgrader
  (`stateupgrade.RenameStringAttr` for a rename); a removal is dropped by every older upgrader
  too. Never bump `Version` without an upgrader - `idform.Wrap` adds one on top (`CLAUDE.md`
  "Managed-service instance resource conventions", "Public ids").
- **A plan that replaces or fails on an unrelated change.** Optional+Computed create-only
  attributes order `UseStateForUnknown()` before `RequiresReplace()` (exemptions: `CLAUDE.md`
  "Plan modifier order"); one that cannot be recreated under its name refuses instead, like
  `frostmoln_secret`. Planning raises no ERROR diagnostic (it blocks `terraform destroy`) unless
  guarded by `req.State.Raw.IsNull()` (`internal/provider/plan_error_diagnostics_test.go`).
- **Credential material in plaintext state or output.** A new secret value (secret key, password,
  token, private key, kubeconfig) is `Sensitive: true`; public keys, key prefixes, `_wo_version` and
  tag keys are not (`api_key` `key`, `s3_credential` `secret_access_key`). For
  a `_wo` triple, `fromAPI` never adopts protected material a GET returns and Update reads `_wo`
  through Create's reader (`internal/provider/writeonly_contract_test.go` points 1-2).
- **An id compared or stored in one spelling.** Compare ids with `pubid.Equal`, never `==`. A
  new resource holding Frostmoln UUID ids gets an `idform.Kinds` entry; never list an id whose
  kind depends on a sibling field or that the API does not encode - a wrong kind plans a
  REPLACEMENT (ADR-0129; `CLAUDE.md` "Public ids").
- **A hardcoded catalog value in provider code** (ADR-0126): a flavor id, version, region/AZ, volume
  or cluster tier, or price as a Go list, `OneOf` validator or schema `Default`. Fetch it
  (`flavors`, `regions`, `volume_tiers`, `*_versions` data sources); defaults come from `isDefault`.
  Test fixtures are permitted; an `examples/` value is practitioner HCL (this repo's reading, not
  ADR-0126's).
- **Wire drift with api-gateway.** A new request/response `json` tag is camelCase and matches
  the backend (`typeVersion`, `typeConfig`, `flavorId`); `retry_after` and `required_permission`
  in `client.go` mirror gateway bodies. Tenant-scoped calls use `/v1/tenants/{t}/...` - a bare
  `/v1/api-keys` or `/v1/images` acts on the caller's HOME tenant (`CLAUDE.md` "API Endpoints Reference").
- **Managed-offer HCL drift.** Type-specific resources (no generic `*_instance`), bare
  `version`, `config` (Map of String), `flavor_id`; references point at computed attributes,
  never literal addresses (`CLAUDE.md` "Managed-service instance resource conventions",
  "Surface Contract doctrine").

## Not worth a comment

- Formatting, vet findings, whitespace/EOF, YAML/JSON syntax - pre-commit (`go-fmt`, `go vet`, the
  pre-commit-hooks set) owns those; `.secrets.baseline` is detect-secrets'.
- `docs/` content or drift - regenerated by `make docs` (`scripts/gen-docs.sh`), and the `Docs`
  workflow's `docs-drift` job fails on a stale tree. Review `templates/` and schema descriptions.
- What the `internal/provider` contract tests already fail on: the replace table, inline child
  collections, scope declarations, the word "engine", internal names in examples, default_tags.
- `CHANGELOG.md`, `.version` (release automation); coverage numbers (`.testcoverage.yml` gate).

## Output

Every finding cites a real `path:line` in the PR head. Say "no issues" plainly when
there are none.
